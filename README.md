## Why NUEcalc?
Traditional NUE tools provide static metrics. NUEcalc introduces:
- System-based NUE decomposition (uptake vs utilization)
- Climate-adjusted NUE (aNUE)
- NUE Stability Index (NSI) for risk assessment
- Nitrogen flow diagnostics
- Automated decision recommendations
This bridges the gap between agronomic theory and real-world decision-making.
